## 1. Chi tiết 3 lỗi tranh chấp trong `dem_xung.c`

### Lỗi 1: Thiếu từ khóa `volatile`
- **Hiện trạng:** Khai báo `static uint32_t so_xung;` (dòng 4).
- **Hậu quả:** 
  - Trình biên dịch khi bật tối ưu hóa (`-O2`, `-Os`) sẽ giả định biến `so_xung` không đổi nếu chỉ xét trong ngữ cảnh của vòng lặp `while(1)`.
  - Trình biên dịch có thể nạp giá trị vào một thanh ghi CPU và chỉ đọc từ thanh ghi đó thay vì đọc lại từ bộ nhớ SRAM mỗi lần lặp.
  - Kết quả: Vòng lặp `while(1)` có thể **không bao giờ thấy giá trị mới** dù xung ngắt vẫn tăng liên tục.

### Lỗi 2: Tranh chấp đọc – ghi (Check-then-Act / Mất xung đếm)
- **Hiện trạng:**
  ```c
  if (doc_so_xung() > 100) {
      so_xung = 0;   /* Dòng 20 */
  }
  ```
- **Kịch bản lỗi:**
  1. `so_xung` đạt 101, lệnh `doc_so_xung() > 100` đánh giá là `true`.
  2. Ngay trước khi thực hiện gán `so_xung = 0`, ngắt `EXTI0_IRQHandler` kích hoạt và tăng `so_xung++` lên 102 (đã phát hiện thêm 1 xung cơ học thật).
  3. Ngắt trả về luồng chính, lệnh `so_xung = 0;` tiếp tục chạy.
  4. **Hậu quả:** Xung thứ 102 vừa đếm được bị xoá mất hoàn toàn (*lost update*).

### Lỗi 3: Đọc/ghi không nguyên tử (*Non-atomic access*)
- Biến kiểu `uint32_t` (32 bit). 
- Trên các kiến trúc vi điều khiển 8-bit / 16-bit (hoặc trên ARM nếu thao tác đọc/ghi bị tách thành nhiều lệnh máy hoặc biến không căn chỉnh 4 byte), việc đọc 32 bit đòi hỏi 2–4 lệnh nạp.
- Nếu ngắt nhảy vào đúng giữa lúc CPU đang đọc byte thấp và byte cao, hàm `doc_so_xung()` sẽ trả về một giá trị rác (*torn read*), ví dụ: đang từ `0x0000FFFF` nhảy sang `0x00010000`, đọc dở dang có thể ra `0x00000000` hoặc `0x0001FFFF`.

## 2. Giải pháp khắc phục chuẩn

Để giải quyết triệt để, ta cần:
1. Thêm từ khóa `volatile` cho `so_xung`.
2. Tạo **vùng găng (*critical section*)** bằng cách tạm thời vô hiệu hóa ngắt khi đọc hoặc reset/trừ số xung đã xử lý trong luồng chính:

```c
#include <stdint.h>
#include <stdbool.h>

/* 1. Thêm volatile để chống tối ưu hóa thanh ghi */
static volatile uint32_t so_xung;

void EXTI0_IRQHandler(void)
{
    so_xung++;
}

/* 2. Đọc an toàn trong vùng găng */
uint32_t doc_va_xoa_so_xung(void)
{
    uint32_t tam;
    
    // Tạm khóa ngắt (hoặc lưu trạng thái thanh ghi ngắt PRIMASK trên ARM Cortex-M)
    __disable_irq();
    tam = so_xung;
    so_xung = 0;      // Đặt lại 0 ngay trong vùng găng, không lo mất xung ngắt xen vào
    __enable_irq();
    
    return tam;
}

int main(void)
{
    while (1) {
        uint32_t xung_hien_tai;
        
        __disable_irq();
        xung_hien_tai = so_xung;
        if (xung_hien_tai > 100) {
            so_xung -= xung_hien_tai; // Trừ lượng đã xử lý thay vì gán 0 tuyệt đối
            __enable_irq();
            
            // Xử lý logic ứng
```
